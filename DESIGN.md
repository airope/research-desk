# Interface design

## System

Compact research workbench. Persistent 180px navigation on desktop, horizontal navigation below 760px. Content leads immediately with a plain task or publication title. White surfaces on #f5f7fa, foreground #17263c, muted #5a687a, borders #dce2e9, primary action #245bb7. System sans; body 13px, labels 12px, metadata 11px, primary heading 24px. Radius 5px. No decorative animation, gradients, hero cards or slogans.

## Components

Tables for queues and catalogue; two source columns for comparison, stacked on narrow screens. Semantic subdued status badges. Consistent native form controls, visible keyboard focus and skip link. Technical IDs, raw JSON and evaluation configuration live in disclosure elements. Dates/authors use readable presentation; retained source data is unchanged. Long identifiers wrap; wide tables scroll within their container.

## Copy

Name actions and entities directly: Review queue, Compare sources, Catalogue, Imports, Evaluation, Withdraw decision. Keep only explanations needed for decisions or recovery. Warnings and exploratory-evaluation limitations remain visible. No uppercase eyebrow labels or promotional copy.

## Catalogue workflow extension

Research dossiers are the main entry point. My catalogues opens the catalogue workflow; the earlier public reference tools remain secondary. Import/search uses a stored preview before confirmation. Catalogue rows lead with publication, status and a concrete next action. Strongest comparison opens first, alternatives and corrections use disclosure. Author summaries show four names with a bounded full-list disclosure. Display-only MathML conversion preserves common mathematical structure while source values remain unchanged. Search forms reveal live filters only for INSPIRE.
