# Frozen title-embedding experiment

The experiment ran locally on 17 September 2026. It does **not** justify integrating embeddings into automatic association. At K=20, lexical and embedding retrieval recovered the same labeled positives. With the deliberately uncalibrated title-only threshold probe, embeddings suggested more synthetic false matches. The production application continues to require human review.

## Reproduce

```sh
uv sync --frozen --extra embeddings
uv run python scripts/evaluate_embeddings.py
# After the first model download, no external model service is needed:
uv run python scripts/evaluate_embeddings.py --offline
uv run pytest tests/test_embeddings_protocol.py
```

PostgreSQL must be available with the application's normal database settings. Temporary evaluation records are inserted into a transaction for each partition and rolled back; the demo catalogue and decisions are not modified. Model files are cached in `.cache/embeddings`, not committed. No API token, GPU, paid inference service or remote execution of model code is used.

## Model and protocol fixed before execution

- Model: `sentence-transformers/all-MiniLM-L6-v2`, Apache-2.0 according to its official model card.
- Immutable revision: `b8903db39f65d93ae28d49a37c4f3fa90c5f94e0`.
- ONNX SHA-256: `6fd5d72fe4589f189f8ebc006442dbb529bb7ce38f8082112682524616046452`; validated before inference. Every downloaded metadata/tokenizer file checksum is recorded in the report.
- CPU ONNX Runtime, full-precision `onnx/model.onnx`, two inference threads, batches of 32. Attention-mask mean pooling and L2 normalization follow the model card; the downloaded pooling configuration is checked. Truncation is 256 tokens. Input is the source title only; DOI, authors, types and labels are not embedded.
- Dataset: the immutable bytes hashed in [embedding-report.json](../data/embedding-report.json), generated by [build_benchmark.py](../scripts/build_benchmark.py). There are 280 records: 180 synthetic and 100 public-source records, with 150 synthetic pair labels and 50 DOI-derived weak pair labels. **No human or expert annotations exist.** DOI weak labels are not independent evidence of identity.
- Existing publication-family development/validation/test assignments are reused, checked for group and DOI leakage. Actual record counts are 180/66/34; final test contains only 11 families, including three synthetic families. No model, threshold or rule selection used the test partition.
- Candidate retrieval uses K=20 within each partition, symmetrized for pair recall, with an **untruncated exact DOI union** for both methods. Lexical retrieval calls the application's actual PostgreSQL `candidate_ids`; embedding retrieval uses top-K cosine. The latter uses a dense matrix for this small experiment, not a production search index. Real weak-label recall is structurally favored by the DOI union.
- A title-only threshold of 0.85 was fixed before execution as a probe for both RapidFuzz title similarity and embedding cosine. Equal numeric thresholds do not mean equal calibration or operating points; this is **not** a precision-matched evaluation. Reported suggestion precision excludes ambiguous labels, which are counted separately.
- A second, identical guard for both probes requires matching document type and no metadata warnings. This exposes the value of metadata constraints without silently attributing it to the embedding model. These experimental probes differ from the conservative application's baseline rule and never write decisions.

The no-DOI subset means pairs where at least one DOI is naturally absent in this dataset, **not** an additional DOI-masking experiment. It has three synthetic positives in final test and zero real weak-label examples. It cannot establish real-world no-DOI performance.

## Measured final-test results

| Measure | Lexical title method | Embedding title method |
|---|---:|---:|
| Synthetic candidate recall@20 | 6/6 | 6/6 |
| Synthetic candidate recall@20 with missing DOI | 3/3 | 3/3 |
| Real DOI weak-label candidate recall@20 | 8/8 | 8/8 |
| Synthetic title-probe correct suggestions | 6 | 6 |
| Synthetic title-probe false suggestions | 3 | 6 |
| Synthetic title-probe ambiguous suggestions | 3 | 3 |
| Synthetic title-probe precision, ambiguous excluded | 6/9 | 6/12 |
| Synthetic guarded-probe precision | 6/6 | 6/6 |
| Real weak-label title-probe recall | 8/8 | 8/8 |

The 95% Wilson interval for synthetic candidate recall 6/6 is approximately 0.610–1.000; missing-DOI 3/3 is approximately 0.438–1.000. Intervals treat pairs as independent, which can be optimistic because variants share families. The report includes numerators, denominators, intervals, all splits, score distributions and individual false/ambiguous suggestions.

The hard negatives illustrate the limitation directly: preprint and journal variants deliberately share an identical title, so both title methods confuse them. Embeddings also score synthetic titles containing added negation highly enough to cross the probe threshold more often than the lexical method. Metadata guards block these constructed conflicts. Neither successful blocking nor the artificial prevalence of these errors estimates deployment accuracy.

The first measured run encoded all 280 titles in approximately 1.25 seconds on macOS ARM64, Python 3.12.14, ONNX Runtime 1.30.0. Download and model loading are excluded. Retrieval timing is reported separately from encoding; it must not be used to claim a fair end-to-end speedup over PostgreSQL. Exact timings vary between runs and the JSON report records the current run.

## Decision and remaining work

Keep embeddings experimental and disabled in the product. This small set shows no candidate-recall gain and illustrates why semantic/title similarity cannot establish publication identity. A future evaluation needs independently annotated real hard negatives and no-DOI matches, larger group-disjoint test sets, validation-only threshold selection, precision-matched comparison, and a scalable retrieval backend before considering integration. The current experiment demonstrates reproducible local model inference and error analysis, not validated scholarly entity resolution.
